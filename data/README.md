# Data directory

This directory holds `train.csv` from the Kaggle competition [Ventilator Pressure Prediction](https://www.kaggle.com/competitions/ventilator-pressure-prediction).

Due to its size and licensing restrictions, the raw data is **not included** in this repository. Follow the "Data preparation" section of the README to download it and place it here as `data/train.csv`.

If stored elsewhere, set the environment variable `VENTILATOR_DATA_PATH` to specify the path.

This directory is ignored by `.gitignore`, so data files will not be committed by mistake.
